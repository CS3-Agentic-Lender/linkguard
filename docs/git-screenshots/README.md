# Git screenshots

Terminal screenshots of real git commands, for the final report. Each person saves theirs in their own folder:

```text
docs/git-screenshots/
├── Nic/
├── Nikoloz/
├── Ibrahima/
└── Dunmi/
```

- Take them all the time, not once per command. The more we store, the more options we have for the report.
- Name each file `sprint<n>-git-<command>-<ALG key or topic>.png`, for example `sprint3-git-status-ALG-100.png`.
- Show the command and its output in the same screenshot.
- Commit them on the feature branch of the ticket you were working on, with that ticket's key, like any other change.
- **Check every screenshot before committing it.** The repo is public, and betterleaks cannot read images. Crop out anything secret: `.env` values, tokens, passwords or a URL from the dataset.

What to collect is listed in `AGENTS.md`, under "Git by hand".
