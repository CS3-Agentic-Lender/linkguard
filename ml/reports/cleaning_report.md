## What each step did

### 1. Duplicate URLs

- A duplicate is a row whose `URL` exactly matches another row's, and the first copy is kept.
- **425 extra copies removed.** 0 URLs had copies with different labels (0 rows removed for that reason).
- **Compared with other analyses' ~808:** that figure counts rows whose numeric feature values match an earlier row's (808 in the raw file), even though their URLs differ. Rows with the same URL number 425. The 808 lookalike rows are kept for now and are being checked for train/test leakage separately.
- Every duplicated URL appears exactly twice, both copies are labelled phishing, and every pair has different page features, so they look like two separate crawls of the same link.

### 2. Missing, empty and out-of-range values

- Out of range means a count below 0, a ratio or rate outside 0 to 1, a score outside 0 to 100, or a 0/1 column or label holding anything else.
- Missing cells found: **0**. Out-of-range values found: **0**.
- **`Title`:** 32,612 pages with no title (`HasTitle = 0`) store the text `0` as their title. **Action: fixed.** The title is blanked and the row kept.
- **0 rows removed.**
- The CSV is read with `keep_default_na=False`, so the 19 `.na` (Namibia) domains stay as text instead of becoming missing values.

### 3. Recode the label

- **The label is inverted.** The raw file uses 1 = legitimate and 0 = phishing. Cleaning sets new label = 1 − raw label, so **1 = phishing** and **0 = legitimate**.
- Every cleaned row was checked against the same row in the raw file and was flipped correctly.
- Label counts after cleaning: **1 (phishing): 100,520**, **0 (legitimate): 134,850**.
